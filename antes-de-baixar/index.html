Antes de baixar

Você comentou MAPA. Essa é a skill que lê outra skill antes de você instalar.

Você manda o link de uma skill do GitHub e ela lê os arquivos sem instalar nem rodar nada. Funciona no Claude Code (no terminal ou no aplicativo do Claude, na aba Code) e você não precisa saber programar.
O que ela entrega

Uma página explicando a skill

  1. Na prática: para que a skill serve e para quem ela não serve.
  2. Quanto custa: uma estimativa de quantos tokens ela gasta só para carregar, com a conta à vista.
  3. O mapa: o processo inteiro desenhado, parte por parte, para você clicar e ver o que cada etapa faz.
  4. O que está errado: o que ela roda, o que envia para a internet e as falhas que achou nos arquivos.
  5. Glossário: cada termo técnico da página explicado em português simples.

No fim vem o veredito: instalar, instalar com ressalva ou não instalar, com o motivo. Veja um mapa de exemplo.

Instalar

Em um comando

O código está aberto em github.com/Guiair21/antes-de-baixar. Para instalar você precisa ter o Node.js no computador.

Claude Code

npx skills add Guiair21/antes-de-baixar --global --agent claude-code

App do Claude (site ou desktop)

  1. No repositório, toque em Code → Download ZIP.
  2. No Claude, vá em Customize → Skills e suba o ZIP.

Depois, é só pedir

/antes-de-baixar https://github.com/dono/repositorio

Para puxar estrelas e issues do repositório ela usa o GitHub CLI (gh), se você tiver. Ler o código diminui o risco, mas o veredito é uma leitura, não uma garantia.
