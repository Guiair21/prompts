A skill que gera imagem dentro do Claude Code

Você digita /gerar-imagem, descreve o que quer e a imagem cai na pasta do projeto.

Quem gera é o Codex, usando a assinatura do ChatGPT. Sem chave de API e sem cobrança por imagem.

Vídeo: Reel no Instagram

Baixe a skill

O arquivo e o passo a passo completo estão no GitHub. Na página de download, clique em gerar-imagem.zip.

Baixar no GitHub

Código aberto: github.com/Guiair21/gerar-imagem

O que você precisa

  1. Claude Code instalado e funcionando.
  2. ChatGPT pago, Plus ou acima. O plano gratuito não gera imagem pelo Codex. No plano Go a OpenAI não confirma que funciona.
  3. Node.js, para instalar o Codex. Baixe em nodejs.org.
  4. Python 3. No Windows, baixe em python.org e marque "Add Python to PATH". No Mac e no Linux normalmente já vem.

Como instalar

Instale o Codex

npm install -g @openai/codex

No Windows, se aparecer "a execução de scripts foi desabilitada", rode uma vez Set-ExecutionPolicy -Scope CurrentUser RemoteSigned, confirme e repita.

Entre com a sua conta do ChatGPT

codex login

Para conferir, rode codex login status. Tem que aparecer "Logged in using ChatGPT".

Coloque a skill no lugar

Descompacte o zip e copie a pasta gerar-imagem inteira para a pasta de skills do Claude Code. Se a pasta skills não existir, crie.

Windows: C:\Users\SEU-USUÁRIO\.claude\skills\gerar-imagem
Mac e Linux: ~/.claude/skills/gerar-imagem

A pasta .claude fica escondida. No Windows, ative "Itens ocultos" na aba Exibir do Explorador. No Mac, aperte Cmd + Shift + ponto no Finder.

Teste

Feche e abra o Claude Code numa pasta de projeto e digite:

/gerar-imagem xícara de café fumegando sobre mesa de madeira, luz de janela, fundo desfocado, sem texto

Em cerca de 1 minuto a imagem aparece em imagens-geradas, dentro da pasta onde o Claude Code está aberto.

Sem ChatGPT pago

Com a extensão Claude in Chrome, o Claude abre o ChatGPT no navegador, escreve o pedido completo e você só aperta enviar. Funciona na conta gratuita, com poucas imagens por dia. A extensão pede um plano pago do Claude. O passo a passo está no GitHub.

O que ela não faz

Texto dentro da imagem, porque o gerador inventa letras. Faça a imagem sem texto e coloque o texto depois em outro programa. Se der erro, a tabela de soluções está no GitHub.
