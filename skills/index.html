As 3 skills que eu mais uso

Contei no meu histórico do Claude, entre as que baixei pra produzir conteúdo.

Os links levam pras versões originais, em inglês, de quem criou cada uma. Pra instalar no Claude Code ou no Codex você precisa ter o Node.js no computador. Cola o comando no terminal e pronto.
25 vezes

humanizer

Tira a cara de inteligência artificial do texto. Caça travessão, frase de efeito em trio, falso contraste e palavra de robô.

Criada por Siqi Chen (blader): github.com/blader/humanizer

Claude Code

npx skills add blader/humanizer --global --agent claude-code

Codex

npx skills add blader/humanizer --global --agent codex

App do Claude (site ou desktop)

  1. No repositório, toque em Code → Download ZIP.
  2. No Claude, vá em Customize → Skills e suba o ZIP.
17 vezes

youtube-full

Puxa a transcrição de vídeo do YouTube e busca canal e playlist sem sair da conversa.

Do repositório ZeroPointRepo/youtube-skills. Usa o TranscriptAPI: 100 créditos grátis, sem cartão, depois US$ 5 por mês. Na primeira vez, o próprio agente pede o seu e-mail e cria a chave.

Claude Code

npx skills add ZeroPointRepo/youtube-skills --skill youtube-full --global --agent claude-code

Codex

npx skills add ZeroPointRepo/youtube-skills --skill youtube-full --global --agent codex

App do Claude (site ou desktop)

  1. No repositório, toque em Code → Download ZIP e descompacte.
  2. Compacte só a pasta skills/youtube-full num ZIP novo.
  3. No Claude, vá em Customize → Skills e suba esse ZIP.

Eu uso no Claude Code. No app ela depende de acesso à internet liberado pra chamar o TranscriptAPI, e eu ainda não testei por lá.

13 vezes

fact-checker

Confere os números e as afirmações do texto na fonte original e só corrige depois que você aprova.

Criada por daymade: github.com/daymade/claude-code-skills

Claude Code

npx skills add daymade/claude-code-skills --skill fact-checker --global --agent claude-code

Codex

npx skills add daymade/claude-code-skills --skill fact-checker --global --agent codex

App do Claude (site ou desktop)

  1. No repositório, toque em Code → Download ZIP e descompacte.
  2. Compacte só a pasta fact-checker num ZIP novo.
  3. No Claude, vá em Customize → Skills e suba esse ZIP.
No app do Claude, skill só funciona com execução de código ligada em Settings → Capabilities. Vale pros planos Free, Pro, Max, Team e Enterprise.
